# HACCO クラフトビールEC — Prototype

## 画面一覧

| ファイル名 | 画面名 | 主な確認ポイント |
|---|---|---|
| `index.html` | トップページ | 年齢確認モーダル・ヒーロービジュアル・商品スクロール |
| `products.html` | 商品一覧 | フィルターサイドバー(PC) / ドロワー(SP)・ソート |
| `product-detail.html` | 商品詳細 | 画像ギャラリー・テイストメーター・アコーディオン |
| `cart.html` | カート | 数量変更・ギフトオプション・熨斗入力 |
| `checkout.html` | チェックアウト | ステッパー・配送日時・支払い方法 |
| `order-complete.html` | 注文完了 | 完了アニメーション・注文番号表示 |
| `taste-quiz.html` | テイスト診断 | 4問の質問カード・進捗バー |
| `taste-result.html` | 診断結果 | タイプ名・おすすめ商品表示 |
| `login.html` | ログイン | 左: ビジュアル / 右: フォーム のスプリットレイアウト |
| `register.html` | 会員登録 | フォーム検証・生年月日選択 |
| `mypage.html` | マイページ | サイドナビ(PC) / タブ(SP)・注文履歴・お気に入り |
| `breweries.html` | ブルワリー一覧 | ヒーローバナー・ブルワリーカードグリッド |

## デザインコンセプト

**ナチュラル醸造所 × 上質な温かさ**

- **カラー**: 生成りベージュ (#F7F2EA) ベース + 琥珀色アクセント (#B85C1A)
- **フォント**: Playfair Display (ヒーロー装飾) + Noto Serif JP (本文・UI)
- **特徴**: 余白大きめ・写真が主役・AIっぽさゼロの手仕事感

## 使い方

1. `index.html` をブラウザで開く
2. バックエンド不要 / 静的HTMLのみで動作
3. 年齢確認モーダルは「はい」を押すと次回から非表示（sessionStorage）
