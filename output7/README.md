# HACCO Prototype

クラフトビール専門 EC サイト「HACCO」のHTMLプロトタイプです。
バックエンド不要・静的HTMLのみで動作します。

## 使い方

`output/index.html` をブラウザで開いてください。  
（Chrome / Safari / Firefox 最新版推奨）

> **注意**: Unsplashの画像読み込みにインターネット接続が必要です。

---

## 画面一覧

| ファイル名 | 画面名 | 主な機能 |

## 技術仕様

- 静的HTML + CSS + Vanilla JS のみ
- `style.css` 1ファイルで全画面のスタイルを管理（CSS変数使用）
- スマートフォンファースト（375px〜）
- Unsplash 画像URL直接埋め込み（インターネット接続必要）
- アイコン：Heroicons SVG インライン実装（絵文字不使用）
