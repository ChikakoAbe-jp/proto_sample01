# デザイン仕様書 — HACCO クラフトビールECサイト

## 1. デザインコンセプト

**トーン・世界観**: ナチュラル高級感 × クラフト温かみ × 写真主役
- 「高級感はあるが堅苦しくない。手作り感とストーリーがある」という顧客要望を体現
- WHISKY TOKAI / NISHIKI MARKET を参考にした余白多め・写真きれいの世界観
- 黒背景バーの重さを避け、琥珀色（ビールの色）を生成りベースに乗せることで温かみを演出

**記憶に残る要素**: 
琥珀色（`--color-primary: #C4852A`）を「ビールの色」として全体に通すカラーシステム。
ヒーローの `Playfair Display` × 日本語キャッチコピーのコントラストが視覚的なアイデンティティを作る。

## 5. コンポーネント仕様

### ボタン
- **Primary**: 背景 `#C4852A` / テキスト白 / 角丸 6px / パディング 12px 24px
- **Secondary**: 透明背景 / ボーダー `#C4852A` / テキスト `#C4852A` → hover で塗り
- **Ghost**: 透明背景 / ボーダー `#E0D9CF` / テキスト `#2D2116`
- **White (ヒーロー用)**: 白背景 / テキスト `#C4852A`
- hover: 色が暗くなるのみ（translateY浮き上がりなし）

### フォーム
- input 高さ: 44px（padding 10px 14px）
- フォーカス時: ボーダー `#C4852A` + glow `rgba(196,133,42,0.12)`
- エラー: 赤（`#d9452a`）ボーダー + テキスト（未実装、本開発で追加）

### カード（商品カード）
- 背景: `var(--color-surface)`
- ボーダー: `1px solid var(--color-border)`
- シャドウ: hover時のみ `0 2px 8px rgba(45,33,22,0.1)`
- 角丸: 8px
- 画像: `aspect-ratio: 1` / `object-fit: cover`

### ナビゲーション
- 形式: スティッキーヘッダー（上部固定）
- 高さ: 64px（`--header-height`）
- スマホ: ハンバーガーメニュー → フルスクリーンオーバーレイ
- アクティブ状態: カレントページのリンクは太字（本開発でJSで制御推奨）

## 8. 実装上の注意点

- **年齢確認**: `sessionStorage` で管理。`ageVerified` フラグが `true` でない場合はモーダル表示。
- **スマートフォンファースト**: 375px〜を基準。`min-width` メディアクエリで段階的拡張。
- **酒類表記**: フッターに「酒類販売業免許 関東第12345号」を必ず表示。
- **Unsplash画像**: ネット接続必須。`onerror` フォールバック実装済み。
- **アイコン**: 絵文字禁止。すべて Heroicons SVG インライン実装。
- **フォント読み込み**: Google Fonts から Noto Serif JP (400/500/700) + Playfair Display (400/700/italic) を読み込む。`display=swap` 必須。
- **ギフトオプション**: チェック時に熨斗入力欄が展開（JS toggle）。
- **商品詳細タブ**: テイストノート/テイストメーター/原材料/ペアリングをタブ切り替え。
- **マイページ**: 注文履歴/お気に入り/登録情報をタブ切り替え。
